# Anson County, NC — GIS County Card

## Summary

Anson County (Charlotte MSA fringe, FIPS **37007**) publishes a surprisingly complete **public** ArcGIS REST stack at `ansoncountygis.com`: countywide **tax parcel polygons** with ownership, mailing, situs, assessed acreage, market/tax values, last-sale price/date, and **joined** `CountyZoning` + `LandUsePlan` codes on `Vector/MapServer/10` (mirrored on `WebApp2026/10`). **Municipal zoning is first-class** on `ZoningLayers` / `WebApp2026` for **Wadesboro, Ansonville (+ETJ), Lilesville, Morven**, plus county unincorporated zoning — but parcels inside towns carry `CountyZoning='Mun.'` / `LandUsePlan='MUN'` placeholders and need a **spatial join** to the town layer. **Peachland and Polkton** zoning MapServer layers exist but are **empty (count 0)**; shapefile ZIP downloads exist for Peachland (and Wadesboro/Morven/Ansonville). **No independent city GIS hosts** found. **NC OneMap** (`cntyfips='007'`) is a solid geometry/owner/value fallback (weak situs/sale). Main gaps: empty Peachland/Polkton REST zoning; McFarlan / White Store / Lanesboro PDF-only; municipal FLU = `MUN` stub; last-sale only (no multi-transfer history); NCGS 132-10 resale limits on downloads.

## Layers (verified)

### 1. Vector/Parcels — parcels + ownership + tax + sale + situs + zoning/FLU codes (PRIMARY)

- **Purpose:** parcels | tax | ownership | sales (last) | situs | zoning (attr) | flu (attr)
- **REST URL:** https://ansoncountygis.com/arcgis/rest/services/Vector/MapServer/10
- **Alternate (same attrs):** https://ansoncountygis.com/arcgis/rest/services/WebApp2026/MapServer/10
- **Layer name / id:** Parcels / 10
- **Geometry:** Polygon
- **Key fields → targets:**
  - `PIN`, `ACCTNUMBER` → parcelId
  - `ASSESSEDACREAGE` → acreage
  - `NAME1`, `NAME2` → ownerName
  - `MAILADDRESS`, `MAILCITY`, `MAILSTATE`, `MAILZIP` → mailing
  - `SITUSADDRESS`, `PHYSADDRESS` → situs
  - `SALEPRICE`, `DATEFLD` → lastSale (date is epoch ms UTC)
  - `TOTMKT`, `CURTOTLND`, `CURTOTBLD`, `CURTOTTOT`, `DEFERVL` → tax
  - `CountyZoning` → zoning (attr; `Mun.` = inside municipality)
  - `LandUsePlan` → flu (attr; `MUN` = municipal stub)
  - `DEEDBOOK`/`DEEDPAGE`, `DESCRIPTION`, `IMPROVEMENT`, `HEATEDSQFEET`, `NBHName` → other
- **WKID / CRS:** 102719 / 2264
- **Verified:** yes — count **19,153**; `ASSESSEDACREAGE BETWEEN 5 AND 150` → **5,820**; `SALEPRICE>0` → **6,610**; sample owner/tax/sale/situs OK
- **Notes:** **PRIMARY** wire-first. Auth **none**. MaxRecordCount **1000** — paginate. `CountyZoning` values include RA-5, RA-3, RA-2, RA-1, R-40, R-20, L-I, H-I, HB, GB, NB, **Mun.** (~6,835). `LandUsePlan` codes: RL, WF, SFN, LLR, LIC, SC, HIC, POS, ROS, AIR, WATER, SO, MFN, **MUN**. Prefer spatial municipal zoning when `CountyZoning='Mun.'`.

## Municipalities (first-class)

## Gaps

- **Peachland + Polkton zoning MapServer layers empty** — ZIP (Peachland) or PDF only.
- **McFarlan / White Store / Lanesboro** — no public zoning REST.
- **Municipal FLU** — parcel attr `MUN` stub; no town FLU FeatureServers; Vision 2040 is PDF policy.
- **`CountyZoning='Mun.'` (~6.8k parcels)** — must spatial-join town layers; attribute alone is insufficient.
- **ZoningLayers attribute query quirk** — prefer objectIds batch or spatial filter.
- **Sale history** is last-sale only (`SALEPRICE`/`DATEFLD`); no multi-transfer FeatureServer.
- **Address points lack PIN** — spatial only; parcel `SITUSADDRESS` usually enough.
- **OneMap** weak situs/sale for Anson; stub out-of-county PINs.
- **MaxRecordCount 1000** on county layers — paginate.
- **NCGS 132-10** — commercial resale of county GIS downloads prohibited; attribution expected.
- **No paid vendor data** used (CoreLogic/Regrid/ATTOM avoided).
- **No phones/emails** collected.

## Hand-off notes for Land Search Builder

1. **Wire first:** `Vector/MapServer/10` — polygons + owner, mailing, situs, acreage, tax, last sale, `CountyZoning`, `LandUsePlan`. Filter `ASSESSEDACREAGE BETWEEN 5 AND 150` (~5.8k).
2. **Municipal zoning:** when `CountyZoning='Mun.'` (or parcel centroid in MunicipalBoundaries), spatial-join Wadesboro/Ansonville/Lilesville/Morven (+ Ansonville ETJ). Leave Peachland/Polkton/McFarlan null or use ZIP.
3. **FLU:** use parcel `LandUsePlan` for countywide codes; treat `MUN` as unknown municipal FLU.
4. **Fallback:** NC OneMap layer 1 with `cntyfips='007'` (filter empty/`Assessed in Union` stubs).
5. **Viewer / appraiser links:**
   - Map: `https://ansoncountygis.com/maps/` (search PIN / owner)
   - Tax Basic Search: `https://www.bttaxpayerportal.com/ITSPublicAN/` (AccountNumber or ParcelNumber)
   - Tax Bill Search: `https://www.bttaxpayerportal.com/itspublican/TaxBillSearch`
6. **Join keys:** `PIN` (preferred), `ACCTNUMBER`, OneMap `parno`↔`PIN`.
7. **Auth:** none observed on listed public query endpoints.
8. **Cities are first-class:** never treat county `CountyZoning` alone as covering Wadesboro/Ansonville/etc. when value is `Mun.`.
