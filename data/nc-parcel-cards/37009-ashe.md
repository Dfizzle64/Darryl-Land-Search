# Ashe County, NC — GIS County Card

## Summary

Ashe County (Boone / Asheville shed, FIPS **37009**, slug **ashe**, `cntyfips='009'`) publishes a strong **public** ArcGIS REST stack at **`gis.ashecountygov.com`**. **Wire-first parcels (TRANCHE-3):** **OpenData/TaxParcel/MapServer/0** — ~**38,839** polys with 12-digit `ParcelNumber`, `GPIN`, owner, mailing, situs (`ParcelPropertyAddress`), `TotalCalculatedAcres`/`LegalLandUnits`, full tax split (`TotalMarketValue`/`TotalAssessedValue`/`ParcelLandValue`/`ParcelBuildingValue`/`ParcelObxfValue`/`ParcelDeferredValue`), deed refs, and **`SalePrice`/`SaleYear`/`DeedDate`**. ~**9,061** with acres 5–150 (~**3,505** with `SalePrice>0` in range). **Zoning is cities-first:** **Jefferson** + **West Jefferson** (+ WJ ETJ) via High Country COG **AsheED_Zoning** FeatureServer; **Lansing** has town limits only (zoning REST gap). **Unincorporated Ashe has no countywide zoning REST** (ordinance-based land-use controls only). **FLU:** Comp Plan 2022 PDF only — no public FLU FeatureServer. **PA deep-link:** `https://gis.ashecountygov.com/ITSPublic/AppraisalCard.aspx?id={ParcelNumber}` (viewer Templates.htm wires Property Record Card). **Jurisdiction GIS:** https://gis.ashecountygov.com/maps/ (`?pin={ParcelNumber}`). **NC OneMap** `cntyfips='009'` geometry/owner/tax fallback (no sale price; saledate empty). Markets: **[Boone, Asheville]**.

## Layers (verified 2026-09-24)

### 1. OpenData/TaxParcel — parcels + ownership + tax + sale (PRIMARY)

- **Purpose:** parcels | tax | ownership | sales
- **REST URL:** https://gis.ashecountygov.com/arcgis/rest/services/OpenData/TaxParcel/MapServer/0
- **Layer name / id:** TaxParcels / 0
- **Geometry:** Polygon
- **Key fields → targets:**
  - `ParcelNumber` → parcelId (PA / viewer / NCPTS key; 12-digit)
  - `GPIN` → parcelIdAlt (map/book style; OneMap `altparno`)
  - `TotalCalculatedAcres`, `LegalLandUnits`, `StatedArea` → acreage
  - `Name1` → ownerName
  - `Address1`–`3`, `City`, `State`, `ZipCode` → mailing
  - `ParcelPropertyAddress` → situsAddress
  - `SalePrice`, `SaleYear`, `DeedDate` → lastSale
  - `TotalMarketValue`, `TotalAssessedValue`, `ParcelLandValue`, `ParcelBuildingValue`, `ParcelObxfValue`, `ParcelDeferredValue`, `PriorTotalValue` → tax
  - `DeedBook`, `DeedPage`, `PlatBook`, `PLATPAGE` → deed
  - `Neighborhood`/`NeighborhoodName`, `FireDescription`, `OwnershipType`, `LegalDescription` → other
- **WKID / CRS:** 102719 / 2264
- **Verified:** yes — count **38,839**; `TotalCalculatedAcres` 5–150 → **9,061**; `SalePrice>0` → **18,077** (in-range **3,505**); `TotalMarketValue>0` → **38,420**; sample ParcelNumber `012090918722` / GPIN `01365293` = BAKER JEFFREY E & NANCY A, SalePrice **55,500**, acres ~**13.83**, centroid ≈ **-81.38, 36.48** (Ashe)
- **Notes:** Best single county layer (includes `TotalCalculatedAcres`). MaxRecordCount **30000**. Auth **none**.

## Gaps / caveats

- **FLU REST gap** — Ashe County Comprehensive Plan 2022 is PDF-only; no county FLU FeatureServer
- **Unincorporated zoning REST gap** — county does not publish countywide zoning polygons (ordinance-based land-use only); cities-first Jefferson/WJ cover incorporated + WJ ETJ
- **Lansing zoning REST gap** — town limits present; no public zoning FeatureServer
- OneMap `saledate` empty for Ashe; `saledatetx` year text only; **no sale price** on OneMap — use TaxParcel `SalePrice`
- Web_Map_2026/16 lacks `TotalCalculatedAcres` field — use OpenData TaxParcel for GIS acres
- County website HTML (`ashecountygov.com`) often **403** from datacenter egress — REST + maps viewer + AppraisalCard + hub verified live
- Utilities / AADT / emails / phones / paid vendors intentionally excluded
