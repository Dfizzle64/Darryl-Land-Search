# Avery County, NC — GIS County Card

## Summary

Avery County (Boone / Asheville shed, FIPS **37011**, slug **avery**, `cntyfips='011'`) outsources public mapping to **AGD** (`agdonline` / `avery.agdmaps.com`). **Wire-first parcels (TRANCHE-3):** **Avery_AGOL/FeatureServer/21 Parcels_Reval** — ~**24,610** polys with 12-digit `PIN` (=`Name`), 17-digit `PARNUM`, owner, mailing/situs, `Calculated_Acreage`/`ACREAGE`, full tax (`TOTAL_VALU`/`LAND_VALU`/`BUILD_VALU`/`XFOB_VALUE`), deed book/page, and **`SALEPRICE`** (+ `DEED_DATE` YYYYMMDD). ~**4,043** with acres 5–150 (~**1,475** with `SALEPRICE>0` in range). Viewer twin **Parcels/5** (~**24,632**) carries `PRC` AppraisalCard deep-link but **no** `SALEPRICE` — prefer /21 for sale. **Zoning is cities-first** via HCCOG **Zoning_Avery_County_Municipalities**: **Banner Elk**, **Sugar Mountain**, **Beech Mountain**, **Seven Devils**. **Newland** (county seat), **Crossnore**, **Elk Park**, **Linville**, **Grandfather Village** — limits only / zoning REST **gap**. **Unincorporated Avery** has no countywide zoning REST (ordinance-based). **FLU:** Planning “Land Use Update” docx link **404** — no public FLU FeatureServer. **PA deep-link:** `http://webtax.averycountync.gov/ITSPublic/AppraisalCard.aspx?id={PARNUM}` (PIN+`00000`; verified PDF). **Jurisdiction GIS:** AGD Avery NC Public Parcel Viewer. **NC OneMap** `cntyfips='011'` geometry/owner/tax fallback (no sale). **Do not use** HCCOG `Avery_County_Parcels` — mislabeled **Ashe** data. Markets: **[Boone, Asheville]**.

## Gaps / caveats

- **FLU REST gap** — Planning “Avery County Land Use Update.docx” link resolves **404** on cms3.revize; no county FLU FeatureServer
- **Unincorporated zoning REST gap** — county does not publish countywide zoning polygons; cities-first Banner Elk / Sugar / Beech / Seven Devils only
- **Newland / Crossnore / Elk Park / Linville / Grandfather Village zoning REST gaps** — town/village limits present; no public zoning FeatureServer
- **HCCOG `Avery_County_Parcels` is wrong geography** — cities Jefferson/West Jefferson/Lansing (Ashe); **do not wire** as Avery
- OneMap `saledate`/`saledatetx` empty for Avery; **no sale price** on OneMap — use Avery_AGOL/21 `SALEPRICE`
- Parcels/5 lacks `SALEPRICE` — use /21 for sale; /5 for `PRC` template discovery
- CRS 103122/6543 (not legacy 102719/2264) — reproject when joining older OneMap if needed
- Utilities / AADT / emails / phones / paid vendors intentionally excluded
