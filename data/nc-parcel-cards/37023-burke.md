# Burke County, NC — GIS County Card

## Summary

Burke County (Hickory / Asheville shed, FIPS **37023**, slug **burke**, `cntyfips='023'`) publishes a strong public ArcGIS stack at **`gis.burkenc.org`**. **Wire-first parcels + CAMA:** `ProdParcelViewFC/MapServer/0` — ~**59,481** polys with `PIN`/`REID`/`PARCEL_PK`, owner, mailing, situs, `CALCULATED_ACRES`, land/bldg/total assessed values, **`PKG_SALE_DATE`/`PKG_SALE_PRICE`** and land-sale fields, `ETJ` municipality routing. ~**8,046** with acres 5–150 (~**2,079** with `PKG_SALE_PRICE>0` in range). **Cities-first zoning** on `PublicAccessAux` (Morganton / Valdese / Connelly Springs / Hildebran / Rutherford College / Glen Alpine / Drexel / Longview / Hickory / Rhodhiss + County Zoning). Prefer **City of Morganton** native `Morganton_Zoning_Latest` / `ZoningAll` inside Morganton. **FLU:** county `PublicAccessAux/19` `F_LU` (~**1,324**). **PA deep-link:** `http://taxweb.burkenc.org/CamaPWA/PropertySummary.aspx?REID={REID}` (also `PARCELPK={PARCEL_PK}`; HTTPS on taxweb fails — use HTTP). **Jurisdiction GIS:** `https://gis.burkenc.org/default.htm?PIN={PIN}`. **NC OneMap** `cntyfips='023'` geometry/owner/tax fallback (no sale price; saledate empty). Markets: **[Hickory, Asheville]**.

## Layers (verified 2026-09-24)

### 1. ProdParcelViewFC — parcels + ownership + tax + sale (PRIMARY CAMA)

- **Purpose:** parcels | tax | ownership | sales
- **REST URL:** https://gis.burkenc.org/arcgis/rest/services/ProdParcelViewFC/MapServer/0
- **Layer name / id:** burke_vector.BURKE.PROD_PARCEL_VIEW_FC / 0
- **Geometry:** Polygon
- **Key fields → targets:**
  - `PIN` → parcelId
  - `REID` → parcelIdAlt / PA key
  - `PARCEL_PK` → parcelIdPk / PA alt
  - `CALCULATED_ACRES`, `DEEDED_ACRES`, `ACREAGE` → acreage
  - `PROPERTY_OWNER` → ownerName
  - `OWNER_MAIL_1`…`OWNER_MAIL_ZIP` → mailing
  - `LOCATION_ADDR`, `PHYADDR_*` → situs
  - `PKG_SALE_DATE`, `PKG_SALE_PRICE` → lastSale (package)
  - `LAND_SALE_DATE`, `LAND_SALE_PRICE` → lastSale (land-only)
  - `DEED_DATE`, `DEED_BOOK`, `DEED_PAGE`, `REVENUE_STAMPS` → deed
  - `TOTAL_PROP_VALUE`, `TOTAL_LAND_VALUE_ASSESSED`, `TOTAL_BLDG_VALUE_ASSESSED` → tax
  - `LAND_USE_VALUE`, `USE_VALUE_DEFERRED` → tax use-value
  - `ETJ` → municipality / zoning router
  - `LAND_CLASS`, `TOWNSHIP`, `VCS` → land-use hints
- **WKID / CRS:** 102719 / 2264
- **Verified:** yes — count **59,481**; `CALCULATED_ACRES` 5–150 → **8,046**; `PKG_SALE_PRICE>0` → **25,673** (in-range **2,079**); `LAND_SALE_PRICE>0` → **14,871** (in-range **2,402**); `TOTAL_PROP_VALUE>0` → **56,914**
- **Notes:** **PRIMARY** for tax/sale/owner. MapServer only (no FeatureServer twin). MaxRecordCount **1000** — paginate. Prefer over VIEWER FS when sale/land-bldg split needed.

## Gaps / caveats

- `taxweb.burkenc.org` **HTTPS fails** (TLS EOF) — CamaPWA deep-links must use **HTTP**
- ProdParcelViewFC is MapServer-only; VIEWER/AGOL FeatureServers omit sale price / land-bldg split
- Rutherford College zoning layer only **7** polygons — treat as incomplete
- No independent Valdese/Hildebran/Drexel/etc. ArcGIS — county-hosted Aux layers are public wire
- OneMap `saledate` empty for Burke; no sale price on OneMap
- NCPTS is SPA — `parcel-detail/{PIN}` pattern matches other NC counties; CamaPWA `{REID}` is authoritative PA
- Utilities and AADT intentionally excluded; no emails/phones/paid vendors
