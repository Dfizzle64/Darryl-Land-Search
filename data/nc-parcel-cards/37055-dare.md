# Dare County, NC — GIS County Card

## Summary

Dare County (Outer Banks / Eastern NC, FIPS **37055**, slug **dare**, `cntyfips='055'`) publishes public cadastral + CAMA on **ArcGIS Online** org `ozZJ6IIlcOT869Kx` and a GeoServer twin at `gs.darecountync.gov`. **Wire-first parcels (ArcGIS REST):** **gis_polygons** FeatureServer/0 — **~47,870** polygons with owner, mailing, situs, GIS/deed acres, full value split (land/bldg/misc/tot), and **parcel-level `zoning`**. **~2,222** with `calcacre` 5–150 (~**943** bldgval 0/null in band). **Sale price** is not on the parcel FS — join **sales_layer** WFS on `id` (**7,622**, `tasaleprice`/`saleval` Q) or **sales_points** on `parcel` (**~30,840** with `sl1price>0`); also county tax **Land Transfer** HTML `parcel.php?parcel={parcel}` and OneMap `saledate`. **Cities-first zoning polygons (GeoServer WFS):** Kill Devil Hills `kdhzones`, Nags Head `nhzones`/`nhzones2`, Manteo `manteozones`, Kitty Hawk `khzones`, Duck `duckzones`, Southern Shores `sszones`, plus county `countyzones` for unincorporated. Parcel `zoning` + `taxdistnam` router covers all munis when polygon FS is unavailable. **FLU:** CAMA Land Use Plan + town LUPs via **NC DEQ** (PDF/edocs) — **no public FLU FeatureServer**; `landClass` is NLCD land-cover (not FLU). **PA:** Spatialest `#/property/{parcel}` + tax bill/cert/land-transfer + NCPTS `{parcel}`. **jurisdictionGisUrl:** https://maps.darecountync.gov/. Markets: **[Outer Banks, Eastern NC]**.

## Gaps

1. **No public FLU FeatureServer** — CAMA LUP / town LUPs are PDF/edocs only; `landClass` is NLCD cover, not future land use.
2. **City zoning FeatureServers** — polygon zoning is GeoServer WFS/WMS only (not AGOL FeatureServer); parcel.`zoning` attribute covers all for attribute joins.
3. **Sale price not on parcel FeatureServer** — must join sales_layer (`id`) / sales_points (`parcel`) or scrape Land Transfer HTML / use OneMap saledate (no price).
4. **AGOL vs WFS count drift** — gis_polygons AGOL **47,870** vs WFS **47,902**; prefer AGOL for ArcGIS REST wiring, WFS for sales joins.
5. **darenc.gov** intermittently **403** from some fetch providers — use maps.darecountync.gov / DEQ / AGOL mirrors.
6. No AADT / utilities / emails / phones / paid vendors collected (per ask).
