# Davie County, NC — GIS County Card

## Summary

Davie County (Winston-Salem MSA, FIPS **37059**) publishes a strong **public** ArcGIS REST stack at `gis.daviecountync.gov`: countywide **tax parcel polygons** with ownership, mailing, situs components, assessed/GIS acreage, and market/assessed values on `Parcels/FeatureServer/7` (BITEK CAMA view). **Last-sale year/month** (no price) lives on `Parcel_Sales` / `WebTemplate2026` Parcels `/26`. **Zoning is municipal-first but county-hosted**: one FeatureServer covers **Davie County (unincorporated) + Mocksville + Bermuda Run + Cooleemee** via `JURISDICTION` + `ZONING` — no independent city GIS hosts found. **FLU** is public for **county land use** (`Hosted/county_landuse`) and **Mocksville Land Use Code**; Bermuda Run / Cooleemee lack dedicated FLU FeatureServers (growth-management polygons only). **NC OneMap** (`cntyfips='059'`) is a solid situs-on-polygon fallback (sale date empty for Davie; no sale price). Main gaps: **no SalePrice on public REST** (ITS HTML Sales Search only); Mocksville land-use only on WebTemplate MapServer; filter rare `NCPIN` stubs (`ROAD`).

## Layers (verified)

### 1. Parcels/FeatureServer/7 — BITEK CAMA parcels (PRIMARY)

- **Purpose:** parcels | tax | ownership | situs (components) | acreage
- **REST URL:** https://gis.daviecountync.gov/server/rest/services/Parcels/FeatureServer/7
- **Alternate (MapServer, same layer id):** https://gis.daviecountync.gov/server/rest/services/Parcels/MapServer/7
- **Layer name / id:** davie_vector.DAVIE.BITEK_VIEW_FC / 7
- **Geometry:** Polygon
- **Key fields → targets:**
  - `NCPIN`, `AccountNumber`, `COUNTYID`, `ParcelID` → parcelId
  - `TOTAL_ACRES`, `ASSESSED_ACRES`, `DEEDED_ACRES` → acreage
  - `Name1`, `Name2` → ownerName
  - `Address1`, `Address2`, `Address3`, `City`, `State`, `ZipCode` → mailing
  - `HouseNumber`, `StreetDirection`, `StreetName`, `StreetType`, `StreetSuffix`, `UnitNumber` → situs
  - `TotalMarketValue`, `TotalAssessedValue`, `ParcelLandValue`, `ParcelBuildingValue`, `ParcelObxfValue`, `ParcelDeferredValue` → tax
  - `CityCode` (`01`=Cooleemee, `02`=Mocksville, `03`=Bermuda Run, null=unincorporated) → jurisdiction hint
  - `TownshipCode`, `LegalDescription`, `PlatBook`/`PlatPage` → other
- **WKID / CRS:** 102719 / 2264
- **Verified:** yes — count **26,678**; `TOTAL_ACRES BETWEEN 5 AND 150` → **5,786**; `ASSESSED_ACRES` 5–150 → **6,041**; `StreetName` non-null → **23,381**; sample owner/mail/situs/tax OK
- **Notes:** **PRIMARY** wire-first for geometry + CAMA. **No sale fields.** Auth **none** on FeatureServer query. MaxRecordCount **2000** — paginate. Do **not** harvest `MortgageHolder` / `MortgageLoanNumber`. Filter bad `NCPIN` (null/short/`ROAD`). MapServer `/7` also queryable.

## Municipalities (first-class)

County parcels are countywide. **Zoning for all three towns plus unincorporated county is on the same county FeatureServer** — prefer that local county host (no separate city ArcGIS found). Join pattern: start from Parcels/7 (2264) → spatial join `Zoning_and_Development` where `JURISDICTION` matches → FLU spatial join when available. Use `CityCode` or Municipal_City_Limits to route.

### Town of Mocksville (county seat)

- **Zoning (county host — preferred / most local public REST):** Zoning_and_Development/FeatureServer/0 filter `JURISDICTION='MOCKSVILLE'` — **322** features; codes CB, CI, FP, GI, GI-CD, GR, HC, HC-CD, NC, NR, NR-CD, OSR, S-P, TC, TND (+ overlays MF-O/MH-O)

### Town of Bermuda Run

## Gaps

- **No SalePrice on any verified public ArcGIS REST layer** — biggest wire gap; ITS Basic Search “Sales Date & Price” is HTML-only.
- **OneMap Davie `saledate` empty** (count 0); no statewide sale price.
- **Bermuda Run and Cooleemee FLU** — no dedicated public FeatureServer (Mocksville only + county land-use with `TOWN` stub).
- **Zoning MapServer query disabled** — use FeatureServer/0 (or WebTemplate `/54`).
- **Address points lack PIN** — situs join is spatial or use parcel components / OneMap.
- **Rare NCPIN stubs** (`ROAD`, short/null) — filter before ingest.
- **Mortgage holder / loan fields** present on Parcels/7 — do not collect.
- **Last-sale only** (year/month); no multi-transfer sales FeatureServer with prices.
- **MaxRecordCount 2000** on county layers; OneMap 5000 — paginate.
- **No paid vendor data** used (CoreLogic/Regrid/ATTOM avoided); no phones/emails collected.

## Hand-off notes for Land Search Builder

1. **Wire first:** `Parcels/FeatureServer/7` — polygons + owner, mailing, situs components, acreage, tax. Filter `TOTAL_ACRES BETWEEN 5 AND 150` (~5.8k) or `ASSESSED_ACRES BETWEEN 5 AND 150` (~6.0k). Exclude bad `NCPIN`.
2. **Sale date join:** `Parcel_Sales/FeatureServer/0` or WebTemplate2026 `/26` on `NCPIN` → compose date from `SaleYear`+`SaleMonth`. **SalePrice = null** unless later sourced from ITS HTML (fragile; not preferred).
3. **Zoning:** spatial join `Zoning_and_Development/FeatureServer/0` in 2264; route by `JURISDICTION` / `CityCode` / Municipal_City_Limits. Optionally add Zoning_Overlay.
4. **FLU:** spatial join Hosted/county_landuse/2 + Mocksville MapServer/51; leave null for Bermuda Run / Cooleemee unless policy PDFs digitized later.
5. **Fallback:** NC OneMap layer 1 with `cntyfips='059'` (situs-on-polygon).
6. **Viewer / appraiser links:**
   - Tax Parcel Viewer: `https://gis.daviecountync.gov/portal/apps/webappviewer/index.html?id=94e9a343877d455db96a5bea6f2e8ca3`
   - Real Estate Search: `https://maps.daviecountync.gov/itsnet/RealEstate.aspx` (Account / parcel / owner)
   - Basic Search (incl. sales price UI): `https://maps.daviecountync.gov/itsnet/BasicSearch.aspx`
7. **Join keys:** `NCPIN` (preferred) ↔ OneMap `parno`; `AccountNumber` for ITS; `COUNTYID` alternate.
8. **Auth:** none observed on listed public query endpoints (FeatureServer preferred for zoning).
9. **Cities are first-class:** never treat county zoning alone as covering Mocksville / Bermuda Run / Cooleemee — filter `JURISDICTION` or spatial-join the full zoning layer.
