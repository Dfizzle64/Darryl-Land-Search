# Hoke County, NC — GIS County Card

## Summary

Hoke County (Fayetteville MSA, FIPS **37093**, slug **hoke**, `cntyfips='093'`) publishes public ArcGIS REST at `maps.hokecounty.org`. **Wire-first parcels:** **Parcels** MapServer/0 — ~**29,570** polygons with owner, mailing, situs (`PHY_ADDRES`), acreage (`TOTAL_ACRE`/`CAL_ACRES`), assessed **`COST_TOTAL`**, and last deed date/book/page (**no sale-price field**). **Cities-first zoning:** Overlays **Zoning**/4 `ZONE` — City of **Raeford** stub **`RAEFORD` (~3,330)** + county districts (**RA-20** ~11,737 primary unincorp, HC/R-8/I/NB/R-15/RMH/RMF/CZ-NB). Gate Raeford with **OperationalLayers Raeford City**/12. **FLU:** Land Use Plan **PDF only** (2005; 2025 update in progress at planhokecounty.com) — no public FLU FeatureServer. **PA:** Tax Card Viewer `Default.aspx?Id={TWN_PIN}-` (+ direct PDF `TaxCards/{TWN_PIN}-01.pdf`); NCPTS secondary. **Jurisdiction GIS:** https://maps.hokecounty.org/maps/. Markets: **[Fayetteville]**.

> **Rural-OZ Pass 1 update (2026-09-28): fixed.** Queries on the county REST server `maps.hokecounty.org` are failing: Parcels/0, OperationalLayers/6 and Overlays/4 all return "Bad login user" (a server-side DB fault; layer metadata still loads). **Primary parcels are now** the county's public AGOL layer https://services1.arcgis.com/7LEXuvWjhz6cyraH/arcgis/rest/services/June2025/FeatureServer/1. It needs no token and has 30,121 polygons. Parcel ID is `TWN_PIN` (populated on all 30,121) and acreage is `TOTAL_ACRE` (5–150 ac → 3,743). The layer has no owner, tax or deed fields, and OneMap CAMA is empty for Hoke, so those attributes are a gap until the county server recovers. Once it does, switch back to Parcels/0. The Raeford cities-first zoning notes below are unchanged, but Overlays/4 zoning queries are failing right now too.

- **Purpose:** parcels | tax | ownership | sales (date only) | situs
- **REST URL (wire-first):** https://maps.hokecounty.org/server/rest/services/Parcels/MapServer/0

- **Layer name / id:** Parcels / 0
- **Geometry:** Polygon
- **Key fields → targets:**
  - `TWN_PIN` → parcelId
  - `MAP_BLK_LO` → parcelIdMap / map-block-lot

  - `OWNER_NAME` / `OWNER_NA_1` → ownerName

## Municipalities (first-class)

County parcels are countywide. **Zoning:** only incorporated city fully in-county is **Raeford** — use `ZONE='RAEFORD'` + City polys first; unincorporated uses county `ZONE` codes (dominated by RA-20). Prefer **most local** zoning. Fort Liberty / Fort Bragg Military Reservation is township/federal — limited private CAMA.

### City of Raeford (county seat — cities-first)

- **Zoning:** Overlays/4 where `ZONE='RAEFORD'` — **3,330** (city stub; no discrete district codes on REST)
- **Boundary:** OperationalLayers/12 Raeford City
- **City planning:** https://www.raefordcity.org/planning-zoning/
- **FLU:** county LUP PDF (Raeford Township / Urban Services Area categories) — no city FLU FS
- **Join:** spatial + ZONE filter

### Unincorporated Hoke

- **Zoning:** Overlays/4 where `ZONE` ∈ {RA-20, HC, R-8, I, NB, R-15, RMH, RMF, CZ-NB}
- **FLU:** county Land Use Plan PDF categories (Rural / Urban Services / Economic Development / etc.)

## Gaps

- **Sale price** not on public ArcGIS REST — deed date/book/page only; COST_TOTAL is assessed/cost, not sale.
- **FLU FeatureServer gap** — 2005 Land Use Plan PDF + 2025 plan update site only.
- **OneMap CAMA empty** for Hoke (`ownname`/`siteadd`/`parval`/`saledate`/`gisacres`) — geometry + `parno`/`recareano` only.
- **Raeford district codes** not published on REST — `ZONE='RAEFORD'` catch-all; confirm with City/County Planning.
- **Parcels FeatureServer** not enabled — MapServer only; MaxRecordCount 1000.
- **OperationalLayers/6** Parcels mirror queries sometimes fail — use dedicated Parcels service.
- **NCPTS** SPA may use internal id; verified PA is Tax Card Viewer / PDF by `TWN_PIN`.
- **Utilities / AADT / emails / phones / paid vendors** excluded by design.
