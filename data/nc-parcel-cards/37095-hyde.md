# Hyde County, NC — GIS County Card

## Summary

Hyde County (markets **[Eastern NC / Outer Banks]**, FIPS **37095**, slug **hyde**, `cntyfips='095'`) publishes public AGOL FeatureServers under org **tpenegar** / **agdonline.maps.arcgis.com** (`services3.arcgis.com/nJbIFHiSnaX0z0hS`). **Wire-first parcels:** **Hyde_AGOL/FeatureServer/3** Tax_Parcels — ~**7,794** polys with owner (`Owner_Name`), mailing (`Owner_Address`), situs (`Street_Num`+`Street_Name`), acreage (`Assessed_Acreage` / `calcacres` / `Deeded_Acreage` / `deedacres`), full tax split (`Parcel_Land_Value_Assd` / `Res_Bldg_Misc_Imprv_Assd_Value` / `Parcel_Misc_Imprv_Value_Assd` / `Parcel_Total_Value` / `Parcel_Total_Taxable_Value` / `Parcel_Total_Def_Exempt_Value`), deed book/page, and ids `Pin_Num` / `REID_1` / `mapid`. ~**2,414** with `Assessed_Acreage` 5–150 (~**2,179** vacant/no bldg in band). **Sales:** **Sales_For_GIS/12** — **228** polys with on-layer `Sale_Price`+`Sale_Year_For` (~**43** in acre band); join to parcels on `REID`=`REID_1` / `PIN_NUM`=`Pin_Num`. **Cities-first:** **no incorporated municipalities**. PRIMARY community zoning is **Ocracoke** under County Code Ch.36 Zoning / Ocracoke Development Ordinance (Municode) — **no zoning FeatureServer**. Mainland townships (Swan Quarter seat, Engelhard, Fairfield, Scranton/Ponzer, Lake Landing, Lake Mattamuskeet) are **unzoned** at REST (CAMA LUP + Subdivision only). **FLU:** DEQ-certified Hyde CAMA Land Use Plan PDF (+ map groups / appendices) — **no FLU FeatureServer**. **PA:** AGD PRC `https://dl.agd.cc/prc/nc/hyde/{REID_1}.pdf` + NCPTS `parcel-detail/{REID_1}` + jurisdiction Experience Builder / legacy webappviewer (`hydecountygis.com`).
