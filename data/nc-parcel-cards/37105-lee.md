# Lee County, NC — GIS County Card

## Summary

Lee County (Raleigh–Durham / Triangle footprint, FIPS **37105**, slug **lee**) publishes consolidated public ArcGIS REST at `lee-arcgis.leecountync.gov` for **Sanford**, **Broadway**, and unincorporated areas (Strategic Services is the shared GIS for city + county). **Wire-first parcels:** **Jurisdictions/JURISDICTIONS** MapServer/1 — ~**35.4k** polygons with owner, mailing parts, **situs** (`PropAddr` + ADR*), acreage, land/bldg appraised values (`APRLAND`/`APRBLDG`/`APRTOT`), last **SaleDate**, tax district, and **TaxCard** PA deep-link by `PARID`. ~**4,932** with `ACRES` 5–150 (~**2,139** with building value 0/null). **Sale price** is **not** on the primary parcel layer — use **Sales/Sales** monthly `ALLSALES*` layers (`PRICE` + `ZONING` + `SALEDT`). **Zoning:** countywide **Zoning shapefile** download (Drive; **26,807** polys, `CurrentZon`) is authoritative — BaseLayers historical Zoning REST layer IDs are **gone** (Layer not found). Partial REST: **ZONING_CITYPLAT** (`ZONE_UDO`, ~1.5k COM/IND-joined). **FLU:** **Place_Types** MapServer/0 (~**31.5k**, Plan SanLee `PlaceType`) — PRIMARY. **NC OneMap** (`cntyfips='105'`) is a solid fallback. Markets: **Raleigh-Durham**.

## Layers (verified)

### 1. Jurisdictions/JURISDICTIONS Parcels — parcels + ownership + tax + situs + sale date (PRIMARY)

- **Purpose:** parcels | tax | ownership | sales (date only) | situs
- **REST URL (wire-first):** https://lee-arcgis.leecountync.gov/arcgis/rest/services/Jurisdictions/JURISDICTIONS/MapServer/1
- **Layer name / id:** Parcels / 1
- **Geometry:** Polygon
- **Key fields → targets:**
  - `PARID` → parcelId (PA deep-link key; 12-digit)
  - `PIN` → parcelIdDisplay (####-##-####-##)
  - `ACRES` → acreage
  - `Owner1`, `Owner2` → ownerName
  - `MailADRNO`…`MailADRSUF`, `MailCity`, `MailState`, `MailZip` → mailing
  - `PropAddr`, `ADRNO`/`ADRSTR`/`ADRSUF`/`ADRDIR`… → situs
  - `SaleDate`, `BOOK`, `PAGE` → lastSale (date/deed; **no price**)
  - `APRTOT`, `APRLAND`, `APRBLDG` → tax
  - `TAXDIST` → taxDistrict / municipality hint (CSF/CBW)
  - `TaxCard` → appraiserSearchUrl (prebuilt)
  - `LEGAL1`–`LEGAL3`, `SUBDIV`, `dwel_*`, `ob_*` → legal / dwelling / outbuilding
- **WKID / CRS:** service extent often **102100 / 3857**; sourceSpatialReference **102719 / 2264**
- **Verified:** yes — count **35,438**; `ACRES` 5–150 → **4,932**; `APRBLDG`=0/null in range → **2,139**; `SaleDate` IS NOT NULL in range → **4,725**
- **Notes:** **PRIMARY** wire-first. MaxRecordCount **1000** — paginate. MapServer only. Geo-check PARID `965783891900` ≈ **-79.141, 35.602** (Lee). Ignore blank/ROW stubs (`PIN` like `ROWY-*`, empty PARID).

- **No paid vendor parcel data** used.
