# Macon County, NC — GIS County Card

## Summary

Macon County (Asheville shed, FIPS **37113**, slug **macon**, `cntyfips='113'`) publishes public ArcGIS REST at **`gis.maconnc.org`**. **Wire-first parcels + CAMA:** **JustParcels/MapServer/0 Tax Parcels** — ~**44,698** polys with `PIN`, `OWNER_NAME`, mailing (`OWNER_ADDR1`/`OWNER_ADDR2`/`CSZ`/`CITY`/`STATE`/`ZIP`), situs `PROP_ADDR`, `ACREAGE`, land/bldg/outbuilding/**assessed** values, **`SALES_PRICE`** + `DATE_RECORDED`/`DATE_RECORDED_TEXT` + `VALID_SALE`, deed `DEED_BK_PG`, and municipal **`ZONE_CODE`/`ZONE_DESC`** (Franklin `F*` + Highlands `H*` prefixes on ~**7,097** parcels). `ACREAGE` 5–150 → **~6,329** (~**3,141** with `BLDG_VALUE` 0/null in band). **Sales history twin:** JustParcels/**1** (~**39,955**; `SalePrice>0` → **~24,801**). **Cities-first zoning:** **Town of Franklin** AdditionalLayers/**24** (**4,138** PIN-joined polys, `Zoning`) + AvineonWebApp/**39** twin; **Town of Highlands** AGOL Zoning_01_2025/**31** (**78**, `DISTRICT`). **Unincorporated = unzoned** (county has no base zoning outside Franklin/Highlands — Comp Plan). **FLU:** county Comp Plan + Highlands 2022 Comp Plan **PDF only** — no FLU FeatureServer. **PA deep-link (PDF):** `https://gis2.maconnc.org/ITSPublic/AppraisalCard.aspx?id={PIN}` (verified). **Tax bill:** `…/ITSPublic/TaxBillSearch/Parcel/{PIN}`. **NCPTS:** `https://lrcpwa.ncptscloud.com/macon/parcel-detail/{PIN}`. **Jurisdiction GIS:** `https://gis2.maconnc.org/maps/default.htm` (Avineon). **NC OneMap** `cntyfips='113'` geometry/owner/tax fallback (~**44,699**; gisacres 5–150 → **~6,358**; **no sale price**). Markets: **[Asheville]**.

## Layers (verified 2026-09-24)

### 1. JustParcels Tax Parcels — parcels + ownership + tax + sale (PRIMARY CAMA)

- **Purpose:** parcels | tax | ownership | sales (attr) | situs | zoning-attr
- **REST URL:** https://gis.maconnc.org/arcgis/rest/services/JustParcels/MapServer/0
- **Cloudpermit FeatureServer twin:** https://gis.maconnc.org/arcgis/rest/services/Cloudpermit/CloudpermitParcels/FeatureServer/0 (~**38,674** — thinner)
- **Layers MapServer mirror:** https://gis.maconnc.org/arcgis/rest/services/Layers/MapServer/8
- **AvineonWebApp mirror:** https://gis.maconnc.org/arcgis/rest/services/AvineonWebApp/AvineonWebApp/MapServer/16
- **Layer name / id:** Tax Parcels / 0
- **Geometry:** Polygon
- **Key fields → targets:**
  - `PIN` → parcelId
  - `ACREAGE` → acreage
  - `OWNER_NAME` → ownerName
  - `OWNER_ADDR1`, `OWNER_ADDR2`, `CSZ`, `CITY`, `STATE`, `ZIP` → mailing
  - `PROP_ADDR` → situsAddress
  - `SALES_PRICE`, `DATE_RECORDED`, `DATE_RECORDED_TEXT`, `VALID_SALE` → lastSale
  - `FIRST_GRANTOR_NAME` → lastSale.grantor
  - `DEED_BK_PG`, `Plat_BK_PG` → deed / plat
  - `LAND_VALUE`, `BLDG_VALUE`, `OUTBUILDING_VALUE`, `ASSESSED_VALUE`, `DEFERMENT` → tax
  - `ZONE_CODE`, `ZONE_DESC` → zoning (municipal attr; F*/H* prefixes)
  - `TOWNSHIP_CODE`, `TOWNSHIP_DESC` → municipality router
  - `YearBillNumber` → tax bill year key
  - `NBR_BLDGS`, `PROP_DESC`, `NEIGHBORHOOD`, `FIRE_DIST` → other
- **WKID / CRS:** 102719 / 2264
- **Verified:** yes — count **44,698**; `ACREAGE` 5–150 → **6,329**; `SALES_PRICE>0` → **25,352**; `ASSESSED_VALUE>0` → **43,799**; `ZONE_CODE` populated → **7,097**; vacant (`BLDG_VALUE` 0/null) in 5–150 → **3,141**; `NBR_BLDGS=0` in 5–150 → **2,778**

## Gaps / caveats

- **Unincorporated unzoned** — no county base zoning REST (by design / Comp Plan)
- **FLU PDF-only** — no FeatureServer (county or Franklin/Highlands)
- OneMap **no sale price**; `saledate` epoch empty — use county `SALES_PRICE`/`DATE_RECORDED`
- Cloudpermit FS count lags JustParcels (~38.7k vs ~44.7k)
- Legacy propcards HTML deep-links removed; use ITSPublic AppraisalCard PDF
- `ZONE_CODE` null on majority of parcels — spatial-join municipal polygons inside limits/ETJ
- All_Sales_2020 is a **2020 snapshot** — prefer live JustParcels sales fields
- Utilities / AADT / emails / phones / paid vendors excluded by design (`UTILITIES` field present but not collected)
