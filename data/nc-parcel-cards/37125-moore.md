# Moore County, NC — GIS County Card

## Summary

Moore County (Fayetteville / Southern Pines footprint, FIPS **37125**, slug **moore**, `cntyfips='125'`) publishes public ArcGIS REST at `gis.moorecountync.gov`. **Wire-first parcels:** **Tax/Tax_Layers** FeatureServer/0 — ~**76,926** polygons with owner, mailing, tax values (land/bldg/total), last sale (`RECENT_SALE_PRICE` / `VALID_SALESDT` / `TRANSDATE` / stamp / deed), `TAX_ACRES`, `TAXJURIS`, PIN/PARID. ~**12,639** with `TAX_ACRES` 5–150 (~**5,859** building 0/null; ~**2,864** `RECENT_SALE_PRICE`>0). **Cities-first zoning** on county host `Planning/Planning_Intranet` **City Zoning** (layer 2) — **1,949** polys, field `ZONE` + jurisdiction `JR` (SP/PH/AB/CG/WP/…). County zoning `Planning_Public/0` **ZCODE** (**639**). **FLU:** `Planning_Public/2` Future Land Use **Class** (**692**). **PA:** BI-Tek ITSPublicMO AppraisalCard `{PARID}` (PDF) + NCPTS `{PARID}`/`{PIN}`. Markets: **[Fayetteville, Southern Pines]**.

## Layers (verified)

### 1. Tax/Tax_Layers — parcels + ownership + tax + sale (PRIMARY)

- **Purpose:** parcels | tax | ownership | sales (last)
- **REST URL (wire-first):** https://gis.moorecountync.gov/server/rest/services/Tax/Tax_Layers/FeatureServer/0
- **Also:** MapServer twin `Tax/Tax_Layers/MapServer/0`
- **Layer name / id:** Parcels / 0
- **Geometry:** Polygon
- **Key fields → targets:**
  - `PARID` → parcelId (PA key)
  - `PIN` → parcelIdAlt / OneMap join
  - `TAX_ACRES` → acreage
  - `NAME`, `NAME2` → ownerName
  - `ADDRESS`, `ADDRESS2`, `CITY`, `STATE`, `ZIP` → mailing
  - `RECENT_SALE_PRICE`, `VALID_SALESDT`, `TRANSDATE`, `STAMP_VAL`, `DEED_BOOK`, `DEED_PAGE` → lastSale
  - `TOTAL_VAL`, `LANDVALUE`, `BUILD_VAL` → tax
  - `TAXJURIS`, `TOWNSHIP`, `NBHD`, `LAND_STAT`, `CLASS`, `YEARBUILT`, `PROP_DESC` → other
- **WKID / CRS:** 102719 / 2264
- **Verified:** yes — count **76,926**; TAX_ACRES 5–150 → **12,639**; BUILD_VAL 0/null in band → **5,859**; RECENT_SALE_PRICE>0 in band → **2,864**
- **Notes:** **PRIMARY** wire-first. MaxRecordCount **2000** — paginate. No situs on polygons. OpenData/taxparcels folder is **token-required** (499) — do not use. Geo-check PARID `00030993` PIN `858111658222` ≈ **-79.377, 35.165** (Southern Pines); PARID `00000001` PIN `865100369836` ≈ **-79.490, 35.443**. Auth: none.

## Gaps

- **Parcel situs not on Tax_Layers** — join Address points or OneMap `siteadd`.
- **OpenData/taxparcels & OpenData/zoning** — token-required; not wireable publicly.
- **ITSPublicMO RealEstateSearch** — returns config 500 at verify; use **AppraisalCard** + TaxBillSearch + NCPTS.
- **iCare** — maintenance page at verify; do not rely as primary PA.
- **City FLU FeatureServers** — not verified for SP/PH/AB/CG; county FLU only.
- **County zoning ZCODE** includes muni-name placeholders — ignore; use City Zoning.
- **Sale history** — last-sale on parcels; multi-year via Valid_Sales_By_Year (not full deed chain).
- **Candor** — edge only; prefer Montgomery.
