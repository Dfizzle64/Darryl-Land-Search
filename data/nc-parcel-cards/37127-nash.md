# Nash County, NC — GIS County Card

## Summary

Nash County (Raleigh–Durham / eastern Triangle footprint, FIPS **37127**, slug **nash**) publishes strong **public** ArcGIS REST at `gis.nashcountync.gov/nashmaps`. Countywide **tax parcel polygons** (~**56,230**; ~**8,347** with `GIS_ACRES` 5–150) carry ownership, mailing, situs (`PHYS_ADDR` on ~82%), last sale date/price/code, and full CAMA values on `PUBLIC/Parcels` FeatureServer/0 (MapServer mirror). Prefer **`TAX_PARID` / `GIS_PARID`** for tax/PA deep-links; **`TAX_PIN` / `GIS_PIN`** (12-digit) for PIN-style joins. **Zoning is cities-first on the county host:** dedicated per-muni layers on `Avineon_WebTemplate` — **Rocky Mount** (2972, field `ZONING`) is the largest; Nashville, Spring Hope, Whitakers, Bailey, and other towns use `ZONE_CODE` + `PLN_JUR`. Unincorporated **County Zoning** (~404) holds Nash County base codes plus muni stubs. **FLU:** Land Development Plan 2022 (900 polys). **NC OneMap** (`cntyfips='127'`) is a solid fallback with situs on polys. No independent Rocky Mount ArcGIS REST found (ViewPro viewer only). Markets: **Raleigh-Durham**.

## Gaps

- No independent Rocky Mount (or other town) ArcGIS FeatureServer — county-host layers + ViewPro viewer only
- Combined County Zoning / OpenGov layers lack muni ZONE_CODE detail (stubs only) — always use per-muni layers 65–75 / 72 inside city limits
- No city FLU FeatureServers — county LDP Municipal Growth placeholder; Rocky Mount comprehensive plan PDF / ViewPro
- PHYS_ADDR null on ~18% of parcels — join Address Points on PARID or OneMap siteadd
- ETJ layer missing several munis; field is `ZONE_` not a clear name alias
- Last-sale only on parcel; Sales/48 is a subset not multi-transfer history
- Tax portal intermittently shows maintenance banner; datalet requires `TAX_PARID` (not 12-digit PIN)
- Elm City city_limits tip is Wilson County core
- MaxRecordCount 2000 — paginate; no phones/emails; no AADT/utilities; no paid vendors on this card

### 4. Owner entity
- Owner fields: `OWNER1`, `OWNER2`. Rule: uppercase/trim, flag if matches regex `(?i)(\bL\.?\s?L\.?\s?C\b|\bINC\b|\bCORP|\bL\.?\s?P\b|\bLLP\b|\bLLLP\b|\bLTD\b|TRUST|CHURCH|MINISTR|\bCOMPANY\b|PARTNERSHIP|PRTNRSHP|HOLDINGS|PROPERTIES|INVESTMENT|ASSOCIATION|\bHOA\b|FOUNDATION|AUTHORITY|\bDEVELOPMENT|BOARD OF EDUCATION|^(CITY|COUNTY|STATE|TOWN|VILLAGE) OF\b|^UNITED STATES|^NORTH CAROLINA\b|\bCOUNTY$)`.
- **Live entity-pattern parcels 5–150 ac: 2107** (of 8306 with owner). Server-side SQL = range AND OR-list of LIKE tokens (see YAML `pass2.ownerEntity.sqlLikeTokens`).
- Caveats: TRUST/TRUSTEE also flags family/revocable living trusts (still non-individual title holders); "% COUNTY" suffix catches e.g. "PERSON COUNTY"; bare "CO" and "ESTATE" intentionally excluded (too many false positives). Some owner strings carry trailing spaces (Wake) or mixed case (Yadkin) — normalize first.
