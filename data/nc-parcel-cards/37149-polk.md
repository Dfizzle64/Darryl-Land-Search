## Gaps / caveats

- **Sale price REST gap** — `DEED_YEAR` / OneMap `saledatetx` only (no `SALE_PRICE` on public layers)
- **FLU FeatureServer gap** — 20/20 Vision Comprehensive listed on docs page; public PDF URL not resolved; no municipal FLU REST
- **TaxParcels stale** — prefer Parcels/0
- **Zoning layer is municipal-aggregated** — route by spatial join / code prefix; unincorp includes ETJ spill + sparse county districts
- **gis.polknc.org** ArcGIS Server SSL broken (EOF) — AGOL org is the wire path
- **PRC host is HTTP :8080** — not HTTPS
- **LU_Parcels ≠ FLU** — do not treat as future land use
- Utilities / AADT / emails / phones / paid vendors intentionally excluded
