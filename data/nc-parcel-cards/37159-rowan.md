# Rowan County, NC — GIS County Card

## Summary

Rowan County (Charlotte MSA, FIPS **37159**) publishes rich **public** ArcGIS REST at `gis.rowancountync.gov`: countywide **tax parcel polygons** with ownership, mailing, **situs on the polygon**, GIS/deed acreage, last-sale date/amount/qualified code, and fair-market tax values on `Public/Open_Data_Downloads` Parcel Polygons (and twins `RowanTaxParcels`, `search`, `MapViewer`). **Zoning is municipality-first** — county unincorporated plus Salisbury, Kannapolis, Cleveland, Landis, Faith, China Grove, Rockwell, Spencer, East Spencer, Granite Quarry on `Public/Alll_Zoning` (also `Municipal_Zoning`). **FLU** public REST found for **Salisbury** (`EnerGov` Future Land Use) and **Kannapolis Character Areas**; other towns = gap. **City of Salisbury** hosts its own parcels FS + EnerGov FLU/Districts. **NC OneMap** (`cntyfips='159'`) is a solid fallback. Main gaps: no countywide FLU; zoning field names differ per town; `LandUse` / `TaxAppraisalInfo` MapServers empty; last-sale only (no multi-transfer history).

## Gaps

- **No countywide FLU FeatureServer** — Salisbury EnerGov FLUM + Kannapolis Character Areas only; China Grove/Cleveland/Landis/Faith/Rockwell/Spencer/East Spencer/Granite Quarry/unincorporated FLU = gap or PDF plans only.
- **Zoning split by municipality with heterogeneous field names** — must coalesce or route layers; merged layer 0 helps via `MERGE_SRC`.
- **`LandUse` and `TaxAppraisalInfo` MapServers empty** (0 layers) — do not wire.
- **`Municipal_Zoning` omits Cleveland** — use `Alll_Zoning` for full coverage.
- **Sale history** is last-sale only on parcels; no multi-transfer sales FeatureServer found on public REST (`parcel_sold_last_30_days` service empty).
- **Open_Data address points lack parcel PIN** — situs already on parcel polygons.
- **Assessed vs market:** public layers expose FMV (`LANDFMV`/`IMP_FMV`/`TOT_VAL`) and present-use land (`LANDLUV`); no separate “assessed taxable” field verified on primary parcel layer.
- **Owner phones/emails** not collected (do not scrape tax site / gismaps PII beyond public REST fields).
- **MaxRecordCount** 1000 on some mirrors; Open_Data / RowanTaxParcels allow **100000** — prefer those; OneMap **5000** — paginate.
- **No paid vendor data** used (CoreLogic/Regrid/ATTOM avoided).

## Hand-off notes for Land Search Builder

1. **Wire first:** `Public/Open_Data_Downloads/MapServer/37` — polygons + owner, mailing, **situs**, acreage, tax, last sale. Filter `CALCACRE BETWEEN 5 AND 150` (~10.4k). Alternate Mercator twin: `Public/RowanTaxParcels/MapServer/0`.
2. **Situs:** already on primary parcels (`PROP_ADDRESS` / street parts). Optional OneMap `siteadd` fallback.
3. **Zoning:** spatial join `Alll_Zoning/MapServer/0` (merged) **or** per-muni layers routed by City Limits `CITY_NAME`. Coalesce zoning fields by `MERGE_SRC`. Prefer Alll_Zoning over Municipal_Zoning (includes Cleveland).
4. **FLU:** spatial join Salisbury EnerGov/5 (`FLUM`) and Kannapolis CharacterUses; leave null elsewhere.
5. **Fallback:** NC OneMap layer 1 with `cntyfips='159'`.
6. **Viewer / appraiser links:**
   - GIS maps: `https://gis.rowancountync.gov/gismaps/`
   - Tax search: `https://tax.rowancountync.gov/search/commonsearch.aspx?mode=realprop` (search by Parcel ID / owner / address)
7. **Join keys:** `PARCEL_ID` (preferred; matches OneMap `parno`), `PIN` (hyphenated map PIN).
8. **Auth:** none observed on listed public query endpoints.
9. **Cities are first-class:** never treat county zoning as countywide coverage.

### 4. Owner entity
- Owner fields: `OWNNAME`, `OWN2`. Rule: uppercase/trim, flag if matches regex `(?i)(\bL\.?\s?L\.?\s?C\b|\bINC\b|\bCORP|\bL\.?\s?P\b|\bLLP\b|\bLLLP\b|\bLTD\b|TRUST|CHURCH|MINISTR|\bCOMPANY\b|PARTNERSHIP|PRTNRSHP|HOLDINGS|PROPERTIES|INVESTMENT|ASSOCIATION|\bHOA\b|FOUNDATION|AUTHORITY|\bDEVELOPMENT|BOARD OF EDUCATION|^(CITY|COUNTY|STATE|TOWN|VILLAGE) OF\b|^UNITED STATES|^NORTH CAROLINA\b|\bCOUNTY$)`.

- Caveats: TRUST/TRUSTEE also flags family/revocable living trusts (still non-individual title holders); "% COUNTY" suffix catches e.g. "PERSON COUNTY"; bare "CO" and "ESTATE" intentionally excluded (too many false positives). Some owner strings carry trailing spaces (Wake) or mixed case (Yadkin) — normalize first.
