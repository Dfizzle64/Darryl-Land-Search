# Surry County, NC — GIS County Card

## Summary

Surry County (Winston-Salem MSA shed, FIPS **37171**, slug **surry**) publishes a strong **public** ArcGIS REST stack at `gis.co.surry.nc.us`. **Wire-first parcels (TRANCHE-3):** `InternalUse/SurryLayers/MapServer/11` — ~**44,434** polygons with Parcel ID, owner, mailing, situs street parts, GIS acres, land/building/total market + assessed, **SalePrice + SaleMonth/SaleYear + QualifiedCode**, deed book/page, and parcel **Zoning** attribute. ~**10,608** with `Calculated_Acreage` 5–150 (~**5,481** with `ParcelBuildingValue=0`). Folder name is `InternalUse` but layer queries with **auth none** (same counts as public `Website_Map` / `Parcels`). **Public viewer mirror (no sale price):** `Website_Map/MapServer/29|30` and `Parcels/MapServer/0`. **Zoning is municipal-first on the county host:** `Website_Map/51` MUNICIPAL ZONING (`MUNICIPALITY` = MOUNT AIRY / ELKIN / DOBSON / PILOT / ELKIN/WILKES) + `52` COUNTY ZONING + `53` OVERLAY. **FLU:** `InternalUse/SurryLayers/23` FUTURE_LAND_USE (coarse, 10 polys) + `25` DobsonLandUse; Land Use Plan 2040 + FLUM also as **PDFs**. **NC OneMap** (`cntyfips='171'`) is a solid fallback with land/improve split (sale date text mostly `/`; **no sale price**). **PA deep-link:** `AppraisalCard.aspx?id={Parcel}` (PDF). Main gaps: no independent city ArcGIS hosts; situs city/zip not on parcel polygons; county FLU REST is coarse; OneMap sale date empty for Surry.

## Layers (verified)

### 1. InternalUse/SurryLayers Parcels — parcels + ownership + tax + sale + zoning attr (PRIMARY)

- **Purpose:** parcels | tax | ownership | sales | situs (street) | zoning (attribute)
- **REST URL (wire-first):** https://gis.co.surry.nc.us/arcgis/rest/services/InternalUse/SurryLayers/MapServer/11
- **Layer name / id:** Parcel / 11
- **Geometry:** Polygon
- **Key fields → targets:**
  - `Parcel` → parcelId (12-digit; PA key)
  - `PARCEL_ID` → dashed display id
  - `Calculated_Acreage`, `LegalLandUnits` → acreage
  - `Name1`, `Name2` → ownerName
  - `Address1`, `Address2`, `City`, `State`, `ZipCode` → mailing
  - `HouseNumber`, `StreetDirection`, `StreetName`, `StreetType`, `StreetSuffix` → situs (street only)
  - `SalePrice`, `SaleMonth`, `SaleYear`, `QualifiedCode`, `VacantOrImproved` → lastSale
  - `TotalMarketValue`, `TotalAssessedValue`, `ParcelLandValue`, `ParcelBuildingValue`, `ParcelObxfValue` → tax
  - `DeedBook`, `DeedPage` → deed
  - `Zoning` → zoning (attribute; prefer polygon layers for authority)
  - `Township`, `Neighborhood`, `LegalDescription` → other
- **WKID / CRS:** 102719 / 2264
- **Verified:** yes — count **44,434**; `Calculated_Acreage` 5–150 → **10,608**; `ParcelBuildingValue=0` in 5–150 → **5,481**; `SalePrice>0` → **23,424** (in 5–150 → **4,869**); `VacantOrImproved='V'` in 5–150 → **6,870**; `TotalMarketValue>0` → **44,336**; sample owner/mail/situs/tax/sale/Zoning OK (e.g. Parcel `502113140113`, SalePrice 425000, Zoning `B4`)
- **Notes:** **PRIMARY** wire-first for TRANCHE-3 (sale + tax + owner). Auth **none** despite `InternalUse` folder. MaxRecordCount **2000** — paginate. Prefer over Website_Map when sale price required.

## Gaps / caveats

1. `Website_Map` / `Parcels` public layers **omit sale price** — use InternalUse/11 (or QUALIFIED SALES/53 / AppraisalCard PDF).
2. `InternalUse` folder label — publicly queryable today; if ever locked, fall back to Website_Map + PA PDF for sales.
3. Situs **city/zip missing** on parcel polygons (mailing `City` is owner mail).
4. County FLU REST is **coarse (10 polygons)**; Mount Airy / Elkin / Pilot lack town FLU REST (PDF only).
5. OneMap `saledatetx` unusable (`/`); no OneMap sale price; `scity` empty.
6. No independent municipal ArcGIS REST hosts — county Website_Map/51 is cities-first source.
7. Elkin/Wilkes fringe zoning (`ELKIN/WILKES`) sits on Surry host — confirm county boundary for Wilkes-side parcels.
8. MaxRecordCount 1000 (Website_Map) / 2000 (InternalUse) — paginate.
9. No AADT / utilities / emails / phones / paid vendors collected (out of scope).
