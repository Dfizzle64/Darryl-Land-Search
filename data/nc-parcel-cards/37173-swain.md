# Swain County, NC — GIS County Card

## Summary

Swain County (Asheville / Western NC, FIPS **37173**, slug **swain**, `cntyfips='173'`) publishes public ArcGIS REST at **`maps.swaincountync.gov`**. **Wire-first parcels + CAMA:** **OperationalLayers/MapServer/4 Tax Parcels** — ~**12,669** polys with `PARCEL_ID`/`ParcelNumber`, owner (`Name1`/`Name2`), mailing (`Address1`/`Address2`/`City`/`State`/`ZipCode`), situs (`ParcelAddr` + `HouseNumber`/`StreetName`/…), `LegalLandUnits`/`DeedAcreage`/`DEED_ACRE`, full tax split (`ParcelLandValue`/`ParcelBuildingValue`/`ParcelObxfValue`/`TotalAssessedValue`/`TotalMarketValue`) + `DeedBook`/`DeedPage`. ~**2,522** with `CAST(LegalLandUnits AS FLOAT)` 5–150 (~**2,466** by `Shape_Area/43560`). **AGOL twin** `Swain_County_Parcels` (~**13,551**) adds numeric `Acreage` + **`Deed_Date`** (sale **date** without price). **Cities-first:** Town of **Bryson City** limits only (OperationalLayers/5 + AGOL Bryson_City_Limits) — **no zoning district FeatureServer**; Bryson City has been developing its first zoning/UDO (historically unzoned). **Unincorporated Swain is unzoned** on public REST (mountain-county pattern; county ordinances = flood/watershed/campground/VAD/etc., not base zoning). **FLU:** **1994 Swain County Land Use Plan** PDF only — no FLU FeatureServer; NCDOT CTP ≠ FLU. **Sale price:** public on **ITSPublicSW AppraisalCard PDF** (not on parcel REST). **PA deep-link:** `https://www.bttaxpayerportal.com/ITSPublicSW/AppraisalCard.aspx?id={PARCEL_ID}` (undashed 12-digit). **Jurisdiction GIS:** https://maps.swaincountync.gov/gis/. **NC OneMap** `cntyfips='173'` — join on **`altparno`** (`parno` empty). Markets: **[Asheville]**.

## Layers (verified 2026-09-24)

### 1. OperationalLayers — Tax Parcels (PRIMARY)

- **Purpose:** parcels | tax | ownership | situs | deed refs
- **REST URL:** https://maps.swaincountync.gov/server/rest/services/OperationalLayers/MapServer/4
- **Layer name / id:** Tax Parcels / 4
- **Geometry:** Polygon
- **Key fields → targets:**
  - `PARCEL_ID`, `ParcelNumber` → parcelId (PA / NCPTS / viewer key)
  - `AccountNumber` → parcelIdAccount
  - `LegalLandUnits`, `DeedAcreage`, `DEED_ACRE` → acreage (strings — CAST for filters)
  - `Name1`, `Name2` → ownerName
  - `Address1`, `Address2`, `City`, `State`, `ZipCode` → mailing
  - `HouseNumber`, `StreetDirection`, `StreetName`, `StreetType`, `StreetSuffix`, `ParcelAddr` → situs
  - `LegalDescription` → legal
  - `DeedBook`, `DeedPage` → deed
  - `ParcelLandValue`, `ParcelBuildingValue`, `ParcelObxfValue`, `ParcelSpecialLandValue`, `ParcelDeferredValue`, `TotalAssessedValue`, `TotalMarketValue`, `AssessedValue` → tax
- **WKID / CRS:** 102719 (latest 2264)
- **Verified:** yes — count **12,669**; `CAST(LegalLandUnits AS FLOAT) BETWEEN 5 AND 150` → **2,522**; `Shape_Area/43560` 5–150 → **2,466**; `Name1 IS NOT NULL` → **12,690**; `TotalAssessedValue` non-empty/non-zero → **12,655**; sample `PARCEL_ID=563500075909` **DICK HOLDINGS LLC**, LegalLandUnits **149.3700**, TotalAssessedValue **295160**, DeedBook/Page **0408/0523**, centroid ≈ **-83.937, 35.458** (Swain / Deals Gap)
- **Notes:** PRIMARY wire-first (powers county GIS viewer). MaxRecordCount **2000** — paginate. Auth **none**. Value fields are **strings**. No `SalePrice` / sale-date fields on this layer.

- **Zoning district REST gap** — Bryson City limits only; UDO/first zoning in development; unincorporated unzoned
- **FLU REST gap** — 1994 Land Use Plan PDF + NCDOT CTP only

- Utilities / AADT / emails / phones / paid vendors intentionally excluded
