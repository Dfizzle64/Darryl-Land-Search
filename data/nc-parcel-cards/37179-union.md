# Union County, NC — GIS County Card

## Summary

Union County (Charlotte MSA; Monroe / Indian Trail / Waxhaw / Stallings corridor) publishes rich **public** ArcGIS REST data via **UC Atlas** (`atlas.unioncountync.gov`), which replaced GoMAPS in 2025. Countywide **parcel polygons** on `OperationalLayers/MapServer/215` include ownership, mailing/situs, mapped/gross acres, total tax value, and last three sales (`s1`/`s2`/`s3`). **Zoning is municipality-first:** ~78k of ~118k parcels fall in cities/towns where ParcelCentroids only stubs `CountyZoning='CITY'` — you **must** use per-town zoning layers (or town-published FeatureServers for Waxhaw/Stallings). Unincorporated zoning is on Union County Zoning (`ZONE`/`ADMIN`). Future land use is a **gap** countywide (only Secrest Short Cut SAP + employment-center scraps). NC OneMap (`cntyfips=179`) is a solid fallback. Appraiser links: Devnet wEdge + Spatialest.

## Layers (verified)

### 1. OperationalLayers Parcels — parcels + ownership + tax + sales (PRIMARY)

- **Purpose:** parcels | tax | ownership | sales (last + prior)
- **REST URL:** https://atlas.unioncountync.gov/server/rest/services/OperationalLayers/MapServer/215
- **Layer name / id:** Parcels / 215
- **Geometry:** Polygon
- **Key fields → targets:**
  - `PID`, `ACCTNO` → parcelId
  - `mapped_acres`, `gross_acres` → acreage
  - `CURR_NAME1`, `CURR_NAME2` → ownerName
  - `CURR_ADDR1`, `CURR_ADDR2`, `CURR_CITY`, `CURR_STATE`, `CURR_ZIPCODE` → mailingAddress
  - `PHYSSTRADD` → situsAddress
  - `s1_SALEDATE`, `s1_SALESAMT`, `s1_DEEDQUAL_CODEDESC` (+ s2/s3) → lastSale / history
  - `TOTVAL`, `FMV_TOTAL` → tax values (totals); ignore zeroed `FMV_LAND`/`FMV_IMPRV` unless validated later
  - `property_use`, `DESC1_DESC`, `DESC1_CODE`, `LAND_TYPE`, `YEARBLT` → other
- **WKID / CRS:** 102100 / 3857 (Web Mercator)
- **Verified:** yes — `returnCountOnly` → **118,043**; `mapped_acres BETWEEN 5 AND 150` → **13,149**; sample attrs confirmed
- **Notes:** Best single county attribute+polygon source. **No usable zoning field** — join ParcelCentroids for admin + unincorp code, else spatial/attr-join municipal zoning. MaxRecordCount 2000 — paginate. Prefer over AGOL clip FeatureServer (partial ~40k).

### 2. ParcelCentroids — jurisdiction + unincorporated zoning stub (JOIN HELPER)

- **Purpose:** zoning (partial) | other (jurisdiction)
- **REST URL:** https://atlas.unioncountync.gov/server/rest/services/ParcelCentroids/MapServer/0
- **Layer name / id:** ParcelCentroids / 0
- **Geometry:** Point
- **Key fields → targets:**
  - `PID` → join to Parcels.PID
  - `CountyZoning` → zoning **only when not `CITY`** (unincorporated codes e.g. RA-40, R-20, LI)
  - `ZoningAdmin`, `MuniAdmin` → municipality routing key (Monroe, Indian Trail, Waxhaw, …)
  - `FireDistrict` → other
- **WKID / CRS:** (service State Plane family; use for attribute join on PID — no geometry join needed)
- **Verified:** yes — count **118,043**; ~39.4k ZoningAdmin=`Union County` with real codes; ~78k `CountyZoning='CITY'` needing town layers
- **Notes:** Fast PID join for `ZoningAdmin` routing. Never treat `CITY` as a zone class.

## Municipalities (first-class zoning / FLU sources)

**Join pattern (county parcels ↔ city zoning):**
1. Attribute-join `ParcelCentroids` on `PID` → get `ZoningAdmin` / `MuniAdmin`.
2. If `ZoningAdmin = 'Union County'` and `CountyZoning ≠ 'CITY'` → use `CountyZoning` or spatial-join OperationalLayers/190.
3. Else route to the municipality layer below (prefer **attribute join on `ACCTNO`/`PID`** when the town layer is parcel-attributed; else **spatial join**).
4. **CRS:** `OperationalLayers` parcels + OperationalLayers town zoning = **3857**. `UNION_COUNTY_LAYERS` town zoning = **2264**. Waxhaw city FS = **3857**. Stallings city FS = **2264**. Reproject when mixing.
5. Cities do **not** publish separate countywide tax parcels — use county Parcels/215 for ownership/tax/sale; city layers for zoning (and Waxhaw/Stallings optionally carry parcel attrs).

## Gaps

- **No single countywide zoning FeatureServer** — must union county + ~14 municipal layers (or route via ParcelCentroids.`ZoningAdmin`).
- **ParcelCentroids municipal zoning is stubbed as `CITY`** (~78k parcels) — cannot skip town layers.
- **No countywide Future Land Use REST** — 2050 plan exists as policy docs; GIS only has SAP/employment scraps. Town FLU largely PDF/comprehensive-plan only (e.g. Indian Trail Comp Plan 2041).
- **`FMV_LAND` / `FMV_IMPRV` zeroed** on live Parcels/215 samples — land vs improvement split unavailable; totals only.
- **Hemby Bridge** lacks a dedicated zoning layer.
- **Mint Hill** in Union is negligible (1 polygon) — use Mecklenburg sources.
- **CRS mismatch** between OperationalLayers (3857) and UNION_COUNTY_LAYERS / Stallings FS (2264).
- **Legacy GoMAPS** (`gis.unioncountync.gov`) returns 404 — do not wire.
- **AGOL Parcels FeatureServer/62** is a ~41k clip, not full county.
- **Owner phones/emails** not on these APIs (correct — do not scrape).
- **MaxRecordCount** typically 2000 (OneMap 5000) — paginate.
- **No paid vendor data** used (CoreLogic/Regrid/ATTOM avoided).

## Hand-off notes for Land Search Builder

1. **Wire first:** `OperationalLayers/MapServer/215` — polygons + owner/mail/situs/acreage/tax totals/last sale. Filter `mapped_acres BETWEEN 5 AND 150` (~13.1k).
2. **Route zoning by municipality:** join ParcelCentroids on `PID` → `ZoningAdmin`. Unincorp → CountyZoning or OpLayers/190. Towns → table above (Waxhaw/Stallings prefer city FeatureServers with ACCTNO/PID attr-join).
3. **CRS:** keep parcel work in **3857** when using OperationalLayers end-to-end; reproject UNION_COUNTY_LAYERS / Stallings FS from **2264** when spatial-joining.
4. **FLU:** treat as gap except Secrest SAP / emp-center overlays; do not invent countywide FLU.
5. **Fallback:** NC OneMap layer 1 with `cntyfips='179'`.
6. **Viewer / appraiser templates:**
   - Tax card: `https://unionnc.devnetwedge.com/parcel/view/{PID}`
   - Market report: `https://property.spatialest.com/nc/union#/property/{PID}/`
   - Map: `https://atlas.unioncountync.gov/maps/`
7. **Join keys:** `PID` / `ACCTNO` (usually equal). OneMap `parno` aligns with PID-style ids in samples.
8. **Auth:** None observed on listed public query endpoints.
9. **Cities are mandatory:** never assume county zoning alone covers Union County land search.

### 4. Owner entity
- Owner fields: `CURR_NAME1`, `CURR_NAME2`. Rule: uppercase/trim, flag if matches regex `(?i)(\bL\.?\s?L\.?\s?C\b|\bINC\b|\bCORP|\bL\.?\s?P\b|\bLLP\b|\bLLLP\b|\bLTD\b|TRUST|CHURCH|MINISTR|\bCOMPANY\b|PARTNERSHIP|PRTNRSHP|HOLDINGS|PROPERTIES|INVESTMENT|ASSOCIATION|\bHOA\b|FOUNDATION|AUTHORITY|\bDEVELOPMENT|BOARD OF EDUCATION|^(CITY|COUNTY|STATE|TOWN|VILLAGE) OF\b|^UNITED STATES|^NORTH CAROLINA\b|\bCOUNTY$)`.
- **Live entity-pattern parcels 5–150 ac: 3387** (of 13149 with owner). Server-side SQL = range AND OR-list of LIKE tokens (see YAML `pass2.ownerEntity.sqlLikeTokens`).
- Caveats: TRUST/TRUSTEE also flags family/revocable living trusts (still non-individual title holders); "% COUNTY" suffix catches e.g. "PERSON COUNTY"; bare "CO" and "ESTATE" intentionally excluded (too many false positives). Some owner strings carry trailing spaces (Wake) or mixed case (Yadkin) — normalize first.
