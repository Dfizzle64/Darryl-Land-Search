# Vance County, NC — GIS County Card

## Summary

Vance County (Raleigh–Durham footprint, FIPS **37181**, slug **vance**) publishes public ArcGIS Online REST through org **pET3krhY1T0smsXf** (`vc-gis.maps.arcgis.com`). **Wire-first parcels:** **Envirolink/FeatureServer/1 — Parcels_AGS**, about **26,557** polygons with owner, mailing, situs, assessed value, deed book/page, and PIN/OWNID/GeoPIN. **NC OneMap** (`cntyfips='181'`) adds land/improve value split (~26,547). **Zoning is cities-first:** City of Henderson Planning FeatureServer (city + ETJ) inside Henderson; **Vance_County_Zoning** for unincorporated Vance; Middleburg/Kittrell have no local zoning FS. **No public FLU polygon REST** (2010 Land Use Plan PDF only). **Sale price/date are not on REST** — join **ustaxdata** account card via `{OWNID}`+`{PIN}`. Markets: **Raleigh–Durham**.

## Gaps and cautions

- No sale price/date on county or OneMap REST — use ustaxdata HTML join (`OWNID`+`PIN`) or deed book/page → ROD.
- No public FLU polygon REST (2010 Land Use Plan PDF only).
- Middleburg / Kittrell lack public zoning FeatureServers.
- NCPTS `/api/getParcelDetails` returned HTTP 500 for Vance tenant on 2026-09-24; SPA routes load; prefer ustaxdata for verified sale/PA attributes.
- `YEAR_BUILT` almost entirely 0/null on REST.
- County `ASSESSMENT` is a single total; use OneMap for land/improve split.
- Envirolink maxRecordCount 1000 — paginate.
- No paid vendor data, phones/emails, AADT, or utilities dig.

## Hand-off notes

1. **Wire first:** Envirolink/1 for countywide polygons, owner, mailing, situs, assessed value, PIN/OWNID, deed refs.
2. **Acreage:** `CALC_ACRE` (GIS); `DEEDACRE`/`DEED_ACRE` as deeded complements; OneMap `gisacres`.
3. **Owner / tax / sale:** owner `OWNNAME`; tax `ASSESSMENT` (+ OneMap `parval`/`landval`/`improvval`); sale via ustaxdata account card.
4. **Situs:** `PHYSADDRES`; enrich with ADP/0 when needed.
5. **Zoning:** cities-first — Henderson Planning/0+1 inside city/ETJ; else Vance_County_Zoning/0; route with Municipal/ETJ boundaries.
