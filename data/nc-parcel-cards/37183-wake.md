# Wake County, NC — GIS County Card

## Summary

Wake County (Raleigh–Durham MSA, FIPS **37183**) publishes unusually rich **public** ArcGIS REST at `maps.wakegov.com` / `maps.wake.gov`: countywide **tax parcel polygons** with ownership, mailing, **situs**, assessed values, last sale date/price, and GIS acreage on `Property/Parcels` (~438.6k parcels; ~**12.4k** with `CALC_AREA` 5–150). **Zoning is municipality-first** but conveniently hosted on one county `Planning/Zoning` MapServer (Raleigh, Cary, Apex, Holly Springs, Fuquay-Varina, Garner, Knightdale, Morrisville, Rolesville, Wake Forest, Wendell, Zebulon, Angier edge, County unincorporated, Airport). **FLU** is public for Raleigh, Cary, Apex, Holly Springs, Fuquay-Varina, Knightdale, Morrisville, Wendell, Garner (character typology), and Wake Forest (coarse LandUse); Rolesville/Zebulon FLU = gap. **NC OneMap** (`cntyfips='183'`) is a solid fallback. Main gaps: no single countywide FLU; zoning/FLU must be routed by `PLANNING_JURISDICTION`; Raleigh zoning missing from county Zoning **FeatureServer** (use MapServer/23 or city host).

## Layers (verified)

### 1. Property/Parcels — parcels + ownership + tax + situs + last sale (PRIMARY)

- **Purpose:** parcels | tax | ownership | sales (last) | situs
- **REST URL:** https://maps.wakegov.com/arcgis/rest/services/Property/Parcels/FeatureServer/0
- **Alternate hosts:** https://maps.wake.gov/arcgis/rest/services/Property/Parcels/FeatureServer/0 ; MapServer/0 (same count)
- **Layer name / id:** Property / 0
- **Geometry:** Polygon
- **Key fields → targets:**
  - `PIN_NUM` → parcelId (NC PIN)
  - `REID` → tax account id / viewer key
  - `PARCEL_PK` → integer PK
  - `CALC_AREA`, `DEED_ACRES` → acreage
  - `OWNER` → ownerName
  - `ADDR1`, `ADDR2`, `ADDR3` → mailing
  - `SITE_ADDRESS`, `STNUM`+`STPRE`+`STNAME`+`STYPE`+`STSUF`, `CITY_DECODE`, `ZIPNUM` → situs
  - `SALE_DATE`, `TOTSALPRICE` → lastSale
  - `LAND_VAL`, `BLDG_VAL`, `TOTAL_VALUE_ASSD` → tax
  - `PLANNING_JURISDICTION` → zoning/FLU router
  - `LAND_CLASS_DECODE`, `TYPE_USE_DECODE`, `PROPDESC` → other land use
- **WKID / CRS:** 102719 / 2264

- **Notes:** **PRIMARY** wire-first. Situs on polygon. No zoning/FLU on this layer — spatial join. MaxRecordCount **2000**. Prefer `CALC_AREA` for GIS acres.

## Gaps

- **No countywide FLU FeatureServer** — must union/route municipal FLU; Rolesville + Zebulon (+ Angier edge) FLU = gap or PDF plans only.
- **Zoning split by municipality** — one MapServer helps, but still must pick the right layer; FeatureServer omits Raleigh (layer 23).
- **Morrisville zoning polygons sparse** (32) — verify coverage; may need town updates.
- **Wake Forest LandUse is coarse** (4 categories) — not a full FLU substitute.
- **Garner FLU character typology** is only **8** polygons — high-level only.
- **Knightdale FLU in Web Mercator (3857)** — transform or attribute-join by PIN.
- **Sale history** is last-sale only on parcels; no multi-transfer sales FeatureServer found on public REST.
- **Tax values are assessed** (`TOTAL_VALUE_ASSD`) — no separate market value field on Property/Parcels.
- **Owner phones/emails** not collected (do not scrape iMAPS / Real Estate PII beyond public REST fields).
- **MaxRecordCount** 2000 on county layers; OneMap 5000 — paginate.
- **No paid vendor data** used (CoreLogic/Regrid/ATTOM avoided).

## Hand-off notes for Land Search Builder

1. **Wire first:** `Property/Parcels/FeatureServer/0` — polygons + owner, mailing, **situs**, acreage, tax, last sale. Filter `CALC_AREA BETWEEN 5 AND 150` (~12.4k). Optional vacant-ish: `BLDG_VAL = 0` (~5.9k in that range).
2. **Zoning:** spatial join county `Planning/Zoning/MapServer/{id}` routed by `PLANNING_JURISDICTION` (table above). For Raleigh prefer MapServer/23 or `maps.raleighnc.gov` Planning/Zoning/0 (not county FeatureServer).
3. **FLU:** spatial (or PIN) join municipal FLU per jurisdiction; leave null for Rolesville/Zebulon/unincorporated beyond ActivityCenters.
4. **Fallback:** NC OneMap layer 1 with `cntyfips='183'`.
5. **Viewer / appraiser links:**
   - Tax Account: `https://services.wakegov.com/realestate/Account.asp?id={REID}`
   - iMAPS: `https://maps.raleighnc.gov/iMAPS/` (search PIN / address)
6. **Join keys:** `PIN_NUM` (preferred), `REID`, `PARCEL_PK`, OneMap `parno`↔`PIN_NUM`.
7. **Auth:** none observed on listed public query endpoints.
8. **Cities are first-class:** never treat County Zoning as countywide coverage.
